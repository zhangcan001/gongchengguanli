## 2026-05-28 / codex/UI / 全页面科技感与动效优化

### 本轮目标

- 使用 `ui-ux-pro-max` 规则优化当前所有页面 UI。
- 在不新增 v1.1 功能、不改后端接口业务逻辑的前提下，增强暗色科技感和动态效果。
- 保持首页智能工程驾驶舱定位，并确保核心页面仍可打开、表格仍清晰可读。

### 已完成

- 在 `frontend/src/styles.css` 进行全局 UI 层增强，未修改后端业务逻辑。
- 增强全局暗色科技背景：增加双层网格、轻量扫描线和环境光动效。
- 增强导航与品牌识别：当前导航态增加脉冲锁定效果，品牌标识增加柔和科技光效。
- 增强页面进入体验：页面容器和卡片采用短时 stagger 动效，遵守 reduced-motion 兜底。
- 增强核心卡片与列表质感：驾驶舱卡片、状态卡、问题卡、归档卡、日志素材卡增加玻璃拟态边缘光、悬停浮起和光泽反馈。
- 增强按钮、提示条、状态徽标、进度条和投递/记录控制台的微交互效果。
- 强化表格阅读体验：表头、行悬停、表格容器阴影和分隔线更清晰，避免为了动效牺牲工程数据可读性。
- 使用 Playwright CLI 巡检首页、智能投递箱、进度看板、一句话现场记录、问题闭环、监理日志、资料归档、系统设置页面均可渲染。
- 使用 390px 宽度复核首页，无横向溢出。
- 清理 Playwright 临时产物和临时本地服务进程。

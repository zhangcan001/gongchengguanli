# v1.0-RC 试用指南

本指南写给真实试用人员。试用重点不是“所有功能都点一遍”，而是用一份真实项目资料跑通：上传进度表、查看进度、记录现场问题、形成问题闭环、生成监理日志、导出并归档。

## 1. 如何启动软件

优先使用桌面端试用包：

```text
frontend/release/win-unpacked/智能工程监理工作台.exe
```

或运行安装包：

```text
frontend/release/Smart-Supervision-Workbench-1.0.0-setup.exe
```

双击后等待本地服务启动。正常情况下软件会在独立窗口中打开，不会打开外部浏览器。

如启动失败，请记录截图，并查看：

```text
%APPDATA%\智能工程监理工作台\data\logs
```

## 2. 如何新建项目

1. 打开软件后进入首页。
2. 点击左侧“项目”或首页“新建项目”。
3. 填写项目名称、项目编号、建设单位、施工单位、监理单位等基础信息。
4. 点击“保存项目”。

建议试用时使用真实项目名称或一个便于识别的测试项目名称。

## 3. 如何上传进度表

1. 点击左侧“智能投递箱”。
2. 选择当前项目。
3. 点击“选择并投递资料”。
4. 选择 Excel 进度表。
5. 上传成功后，列表中会出现投递记录。
6. 对 Excel 文件点击“识别为进度表”。

进入进度识别确认页后，请重点检查：

- 识别的 Sheet 是否正确。
- 表头行和数据开始行是否正确。
- 字段映射是否合理。
- 数据预览中是否有红色 error 或黄色 warning。
- 发布前统计中的原始行数、跳过行数、可导入行数是否符合预期。

有 error 时不能发布；有 warning 时可以确认后发布。

## 4. 如何查看进度看板

1. 发布进度数据后，点击左侧“进度看板”。
2. 选择项目。
3. 查看总体进度、计划/实际偏差、专业卡片、楼栋卡片、楼层热力图。
4. 如导入了权重字段，系统优先使用权重归一化统计。
5. 如没有权重，系统回退为完成率平均。

请重点反馈：

- 实际完成率是否符合原 Excel。
- 计划进度缺失时是否没有误判滞后。
- 楼栋、楼层、专业分组是否准确。
- 滞后任务列表是否有帮助。

## 5. 如何输入现场问题

1. 点击左侧“一句话现场记录”。
2. 选择项目。
3. 输入一句现场情况，例如：

```text
3#楼12层砌体灰缝不饱满，要求施工单位整改。
```

4. 点击“智能识别”。
5. 检查楼栋、楼层、专业、问题类型、问题描述、整改要求。
6. 勾选需要生成的动作。
7. 点击“确认生成”。

确认后可生成巡视记录、问题草稿和日志素材。

## 6. 如何处理问题闭环

1. 点击左侧“问题闭环”。
2. 查看问题列表，或点击“新增问题”手工创建。
3. 选择一个问题查看详情。
4. 按业务进展填写操作内容并点击：
   - 通知
   - 登记回复
   - 登记复查
   - 关闭问题
5. 关闭前请填写复查意见。
6. 可点击“完整度检查”查看闭环资料是否完整。
7. 可导出整改通知单、复查记录或问题台账 Excel。

请重点反馈状态流转是否符合你的实际工作习惯。

## 7. 如何生成监理日志

1. 点击左侧“监理日志”。
2. 选择项目和日期。
3. 查看左侧历史日志和当天素材。
4. 填写城市、天气、填写人等基础信息。
5. 可点击“获取天气”，失败时可手工填写。
6. 点击“AI 分析全部”生成草稿，或点击“AI 润色”只润色部分字段。
7. 在中间表单中人工修改内容。
8. 右侧实时预览确认无误。
9. 点击“确认保存日志”。
10. 点击“导出 Word”。

AI 未配置时，系统会使用本地模板生成基础草稿。

## 8. 如何导出资料

可导出的资料包括：

- 监理日志 Word。
- 巡视记录 Word。
- 整改通知单 Word。
- 整改复查记录 Word。
- 问题台账 Excel。
- 进度分析 Excel。
- 归档资料包。

导出后进入“资料归档”页面查询。可按项目、资料类型、业务来源、日期和关键词筛选。

## 9. 如何备份数据

桌面端进入“系统设置”：

1. 查看本地服务状态和数据目录。
2. 点击“一键备份”。
3. 备份文件保存在：

```text
%APPDATA%\智能工程监理工作台\data\backups
```

备份包含数据库、上传、导出、归档、模板和日志，不包含 backups 目录自身。

## 10. 试用时重点反馈哪些问题

请优先反馈：

- 真实 Excel 是否能识别和发布。
- 字段映射是否准确，哪些字段被误判。
- 错误提示是否能指导你修改 Excel。
- 进度看板是否符合工程判断。
- 一句话记录生成的问题是否可用。
- 问题闭环状态是否顺手。
- 监理日志生成内容是否像真实监理日志。
- Word / Excel 导出格式是否能接受。
- 桌面端启动、关闭、备份是否稳定。
- 哪些步骤仍然需要重复录入。

反馈可使用 [FEEDBACK_TEMPLATE.md](FEEDBACK_TEMPLATE.md)。

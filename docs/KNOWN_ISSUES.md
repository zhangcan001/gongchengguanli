# v1.0-RC 已知问题

本文档记录当前 RC 试用版的已知限制。试用时遇到这些问题不代表数据丢失，但需要在反馈中说明样表、截图和操作步骤。

## 1. 已知 Excel 限制

- 支持常见 `.xlsx` / `.xlsm` 进度表；暂不承诺兼容旧版 `.xls`。
- 多 Sheet 会自动识别最可能的数据表，但复杂封面、说明页较多时可能需要重新上传或整理源表。
- 多行表头已做兼容，但跨很多行、跨大范围合并单元格的表头仍可能识别不完整。
- 图片表头、扫描件、嵌入对象、受保护工作表不支持自动解析。
- 合计、总计、小计、说明行会尽量跳过，但特殊命名仍可能进入预览，需要通过错误/警告识别。
- 公式单元格读取的是工作簿保存时的缓存值；如果 Excel 未重新计算保存，结果可能为空或旧值。
- 百分比支持 `80%`、`0.8`、`80`、`80.00%` 等常见格式；带复杂文字说明时可能产生 warning。
- 日期支持常见日期、Excel serial date 和文件名日期；缺少年份的日期可能按当前年份推断。
- 任务编码、清单编码、施工部位、分部分项等字段仍可能受表头命名影响，需要关注字段映射。
- 当前样例覆盖 `resources/sample_data` 下的标准表、多行表头/合计行、日期/百分比异常、缺计划/缺实际等小型样表，不等于覆盖所有工程表格。

## 2. AI 配置限制

- AI 功能需要用户自行提供 OpenAI 兼容接口、API Key 和模型名。
- API Key 仅本地保存并脱敏显示，但试用人员仍应避免在截图中展示敏感配置。
- 网络不可用、额度不足、模型不可用时，AI 生成会失败或回退到本地模板。
- AI 只生成草稿，不能替代监理人员最终判断。
- 当前 AI 主要用于一句话结构化和日志生成/润色，不支持完整资料审查或法律责任判断。

## 3. 打包限制

- 当前桌面端使用 Electron，不是 Tauri。
- Windows 安装包未进行代码签名，首次运行可能出现系统安全提示。
- 安装包文件名仍显示 `1.0.0`，发布候选标识以文档中的 `v1.0-RC` 为准。
- 默认后端端口为 `127.0.0.1:8765`，端口被占用时会提示，需要关闭占用程序或设置环境变量。
- 解包版目录不可随意删除 `resources` 文件夹，否则后端 exe 或前端资源会缺失。
- 备份依赖系统可用的 `tar` 命令；极少数 Windows 环境可能缺失。

## 4. 归档限制

- 自动归档按当前业务类型和导出结果生成目录，暂不支持用户自定义复杂目录规则。
- 历史文件移动、重命名后，归档记录中的下载路径可能失效。
- 资料包导出仅打包当前系统记录到的归档资料。
- 关闭问题时允许资料不完整，但会提示缺失项；不会强制阻断。
- Word 模板样式已可导出，但不同项目、不同监理表式仍需要后续模板适配。

## 5. UI 已知问题

- 当前默认面向桌面宽屏，窄屏下长表格主要依赖横向滚动。
- 监理日志和问题闭环页面信息密度较高，后续还需要继续拆分局部组件和优化动线。
- 部分按钮文案较长，在极小窗口下可能换行。
- 当前没有完整的可访问性审计，键盘导航和读屏体验仍需专项验证。
- 首次进入无数据页面时，部分模块显示空状态，不代表功能不可用。

## 6. 暂不支持功能

- 云端协同、多用户权限、审批流。
- 手机端 App。
- BIM、电子签章。
- 完整检验批、隐蔽验收、材料报审、危大工程、图纸变更。
- 大规模 OCR 和扫描件自动识别。
- 公司级多项目驾驶舱。
- 竣工资料智能组卷。
